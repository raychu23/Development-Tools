What does "done" have to prove?

Every move is ledger move <task> <state> plus evidence flags. Missing evidence or a failing check means the move is refused.
readyplan
  • owner
  • done-when
  • checks to run
  • non-goals · stop rule
runningclaim
  • own worktree + branch
  • base commit recorded
submittedbuilder
  • --report diff summary
  • ledger runs the checks in the worktree
check fails → refused
verifiedreviewer
  • --reviewer ≠ owner
  • --findings
  • checks rerun
self-review → refused
integratedmerge
  • --merge commit
  • checks rerun on the combined repo
check fails → refused
doneclose
  • --outcome where it lives
  • --prevents path:line, the check that stops this mistake
every moveaudit
  • 1 git commit
  • 1 line in 4 log/ledger.md, never deleted
  • board card after the commit

Off-ramps

  • blocked or failed from running, submitted or verified: needs --cause + who decides
  • back to ready with --note · reviewer can send submitted back to running

If a move fails halfway

  • it undoes its own file edits, worktree and branch
  • the board card is only touched after the commit lands
